# AnemiaLab — entrenamiento de IA clínica

Aplicativo didáctico para explorar métodos de aprendizaje automático con valores de hemoglobina, ferritina y volumen corpuscular medio (VCM).

## Funcionalidades

- Base de pacientes editable y persistencia local en el navegador.
- Rotulación de pacientes según el criterio de una médica.
- Entrenamiento y explicación paso a paso de K-Means.
- Cálculo detallado de centroides con fórmulas LaTeX.
- Clasificación supervisada mediante KNN.
- Espacio diferenciado para SVM.
- Explorador 3D con rotación, zoom, centroides y datos clínicos emergentes.
- Estandarización opcional de las variables.

## Uso

No requiere instalación ni servidor. Descarga el repositorio y abre `index.html` en un navegador moderno.

> Este aplicativo tiene fines educativos. Sus agrupaciones y clasificaciones no sustituyen la valoración ni el diagnóstico médico.
